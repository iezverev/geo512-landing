# Сайт производителя дронов

Проект сайта компании, которая разрабатывает, производит и продаёт дроны.
Текущее состояние: согласование структуры и требований. Реализация сайта ещё не начата.

Репозиторий проекта: [iezverev/geo512-landing](https://github.com/iezverev/geo512-landing).

## Основной пользовательский путь

Лендинг изделия → CTA в конце страницы → конфигуратор → выбор комплектации дрона → добавление дополнительного оборудования → состав заказа.

Способ отправки, оплаты и дальнейшей обработки заказа ещё не выбран.

## Как ведём документацию

Фиксируем согласованные решения по мере обсуждения. Предложения и открытые вопросы явно отделяем от принятых требований. Ответ по очередному блоку отражаем в разборе референса и структуре сайта; принятое решение с основанием добавляем в журнал. Визуальные решения также отражаем в документе о визуальном направлении.

## Хранение файлов на GitHub

Всю документацию и создаваемые файлы проекта сохраняем в указанном репозитории. После каждого завершённого изменения проверяем состав файлов, создаём коммит и отправляем его на GitHub. Перед отправкой учитываем актуальные изменения второго участника; существующие файлы и историю не перезаписываем принудительно.

Секреты, пароли, локальные настройки доступа, временные файлы и устанавливаемые зависимости в репозиторий не включаем. Если отправить изменения не удалось, явно сообщаем об этом: локальное сохранение само по себе не означает публикацию на GitHub.
